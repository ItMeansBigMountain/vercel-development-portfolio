SSH NOTES


SSH
    the ssh service needs to be open and port specified , default is 22
    - ssh  [USERNAME]@<ip address>
    - ssh  sosai@192.168.1.101

AWS SSH <connect>
    make sure you have an instance with aws 
    create keyys file.pem
    - ssh -i "KEYS.pem" USERNAME@<ip address>
    - ssh -i "oyama.pem" ubuntu@ec2-18-189-2-102.us-east-2.compute.amazonaws.com

AWS SSH <send files>
    Folder --> scp -i "oyama.pem" -r FOLDER_NAME ubuntu@ec2-3-131-97-55.us-east-2.compute.amazonaws.com:~
    File --> scp -i "oyama.pem" FILE_NAME ubuntu@ec2-3-131-97-55.us-east-2.compute.amazonaws.com:~
