# Codology Direction

Codology should absorb algorithm examples from the `algos` repo and become the interactive coding-practice layer for the school platform.

## Immediate import target

See `ALGOS_IMPORT_PLAN.md` and `ALGOS_IMPORT_PLAN.json`. Current scan found 112 candidate exercises across `algos` branches: `java`, `main`, `pi`, and `school`.

## Learning features

- Lessons generated from algorithm files.
- Runnable examples with source traceability.
- Student progress and mastery tracking.
- Teacher notes and test-result updates.
- Parent dashboard showing understandable progress summaries.
