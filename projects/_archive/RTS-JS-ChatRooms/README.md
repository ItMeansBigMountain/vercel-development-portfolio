# RTS-JS-ChatRooms

## Overview
This project is a web server that allows the creation and use of chat rooms using web, RTS, and Agora JavaScript libraries. It features a Flask web server and has been deployed on Azure Cloud.

## Current Functionality
- Users can create and join chat rooms
- Real-time messaging using RTS and Agora
