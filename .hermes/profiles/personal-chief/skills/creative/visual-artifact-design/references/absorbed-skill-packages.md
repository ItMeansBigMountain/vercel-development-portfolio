# Absorbed Skill Packages

Original packages were archived intact after their class-level guidance was folded into `visual-artifact-design`.

- `architecture-diagram`: polished dark SVG/HTML system diagrams and template.
- `excalidraw`: editable hand-drawn diagram JSON, examples, colors, dark mode, upload script.
- `sketch`: throwaway HTML mockups and multi-variant design exploration.
- `p5js`: p5.js generative/interactive sketches, references, templates, render/export scripts.
- `pretext`: browser text-layout demos, patterns, and starter templates.
- `design-md`: Google DESIGN.md token authoring, validation, and starter template.
- `ascii-art`: pyfiglet/cowsay/boxes/toilet/image-to-ASCII workflows.
- `ascii-video`: ASCII video/GIF pipeline with effect, shader, scene, optimization, and composition references.
- `baoyu-infographic`: infographic layout/style gallery, analysis framework, prompts, and structured content templates.
