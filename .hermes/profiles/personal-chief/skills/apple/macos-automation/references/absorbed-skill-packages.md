# Absorbed Skill Packages

This umbrella absorbed these formerly separate Apple/macOS skills. Their original packages were archived intact rather than flattened, so any package-specific details remain recoverable from the archive.

- `apple-notes`: Apple Notes via `memo` CLI.
- `apple-reminders`: Apple Reminders via `remindctl`.
- `imessage`: iMessage/SMS via `imsg`.
- `findmy`: Find My/AirTag workflows using screenshots and UI automation.
- `macos-computer-use`: background-safe macOS GUI automation patterns.
