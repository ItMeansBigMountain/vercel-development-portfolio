# Absorbed Skill Packages

Original packages were archived intact after their class-level guidance was folded into `document-production-workflows`.

- `nano-pdf`: natural-language PDF edits, examples, prerequisites, and notes.
- `ocr-and-documents`: PDF/scanned document extraction using web extraction, PyMuPDF, and marker/OCR scripts.
- `powerpoint`: `.pptx` reading, editing, generation, QA, and bundled Office helper scripts.
- `research-paper-writing`: ML paper design-to-submit workflow with conference templates, writing guides, and checklists.
