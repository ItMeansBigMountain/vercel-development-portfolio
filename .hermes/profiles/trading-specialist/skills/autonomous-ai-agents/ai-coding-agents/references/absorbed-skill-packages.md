# Absorbed Skill Packages

Original packages were archived intact after their class-level guidance was folded into `ai-coding-agents`.

- `claude-code`: Claude Code CLI orchestration, print mode, interactive mode, flags, and PR workflows.
- `codex`: OpenAI Codex CLI one-shots, background tasks, PR reviews, and parallel worktrees.
- `opencode`: OpenCode CLI binary resolution, one-shot tasks, interactive sessions, and reviews.
- `kanban-codex-lane`: Hermes Kanban worker + Codex isolated lane ownership, prompt template, monitoring, and handoff.
- `subagent-driven-development`: `delegate_task` execution, two-stage review, context budget, and gate taxonomy.
