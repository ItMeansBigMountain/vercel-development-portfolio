## Portfolio review pattern

When inventorying many projects, use status buckets instead of one flat list:

1. **Finished / set aside** — deployed or completed, maintenance-only.
2. **Ship / operate** — active automations or live apps that need reliability.
3. **Incubate / monetize** — promising apps to flesh out.
4. **Upcoming focused lane** — projects the user explicitly wants later (e.g., OSRS plugins).
5. **Archive / freeze** — old exercises, notes, or prototypes.

This prevents completed client work from repeatedly being pulled back into active build planning.
