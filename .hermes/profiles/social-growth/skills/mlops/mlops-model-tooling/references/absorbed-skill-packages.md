# Absorbed Skill Packages

Original packages were archived intact after their class-level guidance was folded into `mlops-model-tooling`.

- `huggingface-hub`: hf CLI search/download/upload and Hub interactions.
- `llama-cpp`: GGUF discovery, quantization, local inference, server mode, and optimization.
- `serving-llms-vllm`: vLLM serving, quantization, deployment, troubleshooting, and optimization.
- `evaluating-llms-harness`: lm-eval-harness quick starts, benchmark guide, custom tasks, API evaluation, and distributed eval.
- `weights-and-biases`: W&B installation, run logging, sweeps, artifacts, integrations, and dashboards.
- `segment-anything-model`: SAM prompts, automatic masks, batching, ONNX, troubleshooting, and advanced usage.
- `obliteratus`: refusal-abliteration/model-surgery workflow requiring before/after evaluation.
