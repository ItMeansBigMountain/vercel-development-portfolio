# Laconic high-ticket interview pattern

This reference captures a session-specific learning for high-ticket offer discovery interviews.

## What happened

The user was exploring a possible $3k+ digital offer from a life story involving:

- Pakistani-American identity conflict
- fatherlessness and authority problems
- being a fat/overstimulated gamer kid
- addiction and self-improvement cycles
- martial arts as discipline and surrogate structure
- getting kicked out of high school
- creating a self-directed coding education path
- teaching kids/adults to code
- landing a cloud engineering job without college
- remote-work mobility and family financial pressure

The assistant initially reflected well but asked too many questions at once. The user explicitly said to slow down and that the responses were too wordy.

## Durable lesson

For this user's offer-discovery interviews, the value is in focused extraction, not comprehensive questionnaires.

Use this rhythm:

1. Reflect the single strongest signal in 2–5 bullets.
2. Ask one decisive question, or at most three.
3. Let the user keep telling the story.
4. Only synthesize after a stage is truly complete.
5. Keep stage labels visible so the process still feels structured.

## Story collection mode

If the user shifts from answering the offer interview into recounting personal chapters, pause the formal stage progression. The user explicitly wants important lived experiences remembered and collected, not treated as disposable project context.

Good behavior:

- Acknowledge briefly.
- Save durable themes/details through the available memory/fact system when appropriate.
- Ask a tiny continuation prompt such as "What happened after that?"
- Do not force Stage 2/3 extraction while the story is still unfolding.
- Later, organize the story into transformation threads only after the user finishes the chapter.

Recent story chapters added after the first correction included: a serious cross-border Pakistani family romance, running away to Houston, brief homelessness while working from a car, the breakup and lasting relationship intensity pattern, and a separate age-19 winter car-homelessness moment that pushed the user back toward school/coding.

## Good response shape

```md
Got it. The strongest signal is: <one sentence>.

I’m hearing:
- <short bullet>
- <short bullet>
- <short bullet>

Stage <n>: <name>.

One question:
<question>
```

## Avoid

- Long lists of 6+ questions.
- Repeating everything the user said in polished prose.
- Prematurely naming the offer.
- Moralizing the story.
- Turning family conflict or trauma into marketing copy before the user chooses the audience.
