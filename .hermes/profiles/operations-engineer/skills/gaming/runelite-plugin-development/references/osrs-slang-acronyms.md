# OSRS slang/acronym reference for narrow RuneLite UI

User supplied the OSRS Wiki slang dictionary as `message.txt` in the July 2026 Who's Grinding Panel shipping session. Use it as a reference for concise RuneLite sidebar labels.

Preferred unambiguous labels already used in Who's Grinding Panel:

- Chambers of Xeric -> `CoX`
- Chambers of Xeric Challenge Mode -> `CM CoX`
- Theatre of Blood -> `ToB`
- Theatre of Blood Hard Mode -> `HMT`
- Tombs of Amascut -> `ToA`
- Corrupted Gauntlet -> `CG`
- Kalphite Queen -> `KQ`
- King Black Dragon -> `KBD`
- Corporeal Beast -> `Corp`
- Cerberus -> `Cerb`
- Phosani's Nightmare -> `PNM`
- The Nightmare -> `NM`
- Thermonuclear Smoke Devil -> `Thermy`
- Wintertodt -> `WT`
- TzKal-Zuk -> `Zuk`
- TzTok-Jad -> `Jad`
- Vardorvis -> `Vard`
- The Leviathan -> `Levi`
- The Whisperer -> `Whisp`
- Venenatis -> `Vene`
- Sarachnis -> `Sarach`
- Zalcano -> `Zalc`
- Last Man Standing -> `LMS`
- Bounty Hunter -> `BH` or `Bounty Hunter` if space allows
- Soul Wars -> `SW`
- Pest Control -> `PC`
- Barbarian Assault -> `BA`
- Castle Wars -> `CW`
- Guardians of the Rift -> `GotR`
- Volcanic Mine -> `VM`
- Collection Log -> `Col Log`

Avoid ambiguous acronyms when they may confuse the card. Example: `GG` can mean Grotesque Guardians or Good Game; use it only in a boss context, and prefer readable labels like `Bandos` over `GG` for General Graardor.
